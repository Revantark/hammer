# Hammer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Hammer, a minimal macOS app launcher + clipboard manager (Swift + AppKit) that stays ≤10 MB idle and ≤30 MB with its panel open.

**Architecture:** Three SwiftPM targets. `HammerCore` holds all logic (matching, ranking, history, persistence, settings, panel state machine, controllers), talking to the system only through small protocols, so it is fully unit-testable with fakes. `HammerMac` holds the AppKit/Carbon/ImageIO adapters that implement those protocols and the Frost UI. `Hammer` is a tiny executable that wires everything in an `AppDelegate`. A build script wraps the binary in a signed `.app`.

**Tech Stack:** Swift 6.2 (language mode 6), AppKit, Carbon (`RegisterEventHotKey`), ImageIO, CoreServices (FSEvents), ServiceManagement (`SMAppService`), CryptoKit, Swift Testing (`import Testing`). No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-13-hammer-design.md`

## Global Constraints

- macOS only, minimum macOS 15 (`platforms: [.macOS(.v15)]`); owner runs macOS 26.
- Swift + AppKit only. **No SwiftUI, no GPUI, no web views.** No third-party packages.
- Memory (`phys_footprint`, Activity Monitor "Memory"): **≤ 10 MB idle**, **≤ 30 MB panel open** (including a 2560×1600 image preview).
- Latency: hotkey → visible panel **< 50 ms**; keystroke → updated results **< 16 ms**.
- Clipboard history capacity: **25** entries, text + images, newest first, persisted under `~/Library/Application Support/Hammer/`.
- Record **everything**, including `org.nspasteboard.ConcealedType` / `TransientType` copies. Skip copies containing file URLs (Finder files).
- Default hotkeys: launcher **⌘Space** (`keyCode 49`, command), clipboard **⌥X** (`keyCode 7`, option). Both changeable in Settings.
- App folders: `/Applications`, `/System/Applications` (incl. `Utilities`), `~/Applications`; recurse, never descend into `.app` bundles.
- Look: "Frost" — dark `NSVisualEffectView`, 14 pt corner radius, 1 px light border, launcher ~620 pt wide, clipboard ~760 pt wide, rows ~36 pt, 24 pt icons, footer with key-cap hints. Dark appearance only. System font. No show animation.
- No Dock icon (`LSUIElement` / `.accessory`). Menu bar icon with "Settings…" and "Quit Hammer", hideable.
- Tests: Swift Testing; no real sleeps, injected clock, temp directories only, no shared global state, order-independent. Suite must pass 5 runs in a row.
- `HAMMER_DATA_DIR` env var overrides the data directory (used by scripts; never point tests at real user data).

## Review Focus

1. **Huge text copy** (e.g. a 5 MB log): history index and search must use a ≤2,000-char snippet; preview loads ≤20,000 chars; memory stays in budget. → Task 5 test `hugeTextIsSnippeted`, Task 12 test `previewCapsText`.
2. **Odd queries** — leading/trailing spaces, `c++`, emoji, only whitespace: no crash, whitespace-only behaves like empty. → Task 1 tests `trimsWhitespace`, `specialCharacters`.
3. **Same app in two folders** (same bundle ID in `/Applications` and `~/Applications`): show once, prefer `/Applications`. → Task 3 test `dedupesByBundleIDPreferringApplications`.
4. **New copy arrives while the clipboard panel is open:** list refreshes but the selection stays on the entry the owner was looking at. → Task 8 test `selectionFollowsIDWhenItemsChange`.
5. **Mixed pasteboard content** — Safari "Copy Image" (image + URL text) must be an image; Word/Pages text (text + rich text + image preview) must be text. → Task 5 tests `imageWithURLTextIsImage`, `richTextWithPreviewImageIsText`.

### Task 5: Clipboard models, classifier, history

**Files:**
- Create: `Sources/HammerCore/Clipboard/ClipModels.swift`, `Sources/HammerCore/Clipboard/ClipClassifier.swift`, `Sources/HammerCore/Clipboard/ClipHistory.swift`, `Tests/HammerCoreTests/ClipClassifierTests.swift`, `Tests/HammerCoreTests/ClipHistoryTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public struct Representation: Codable, Equatable, Sendable { public let type: String; public let data: Data }   // type = UTI string
  public struct PasteboardSnapshot: Equatable, Sendable { public let representations: [Representation]; public let sourceApp: String? }
  public enum ClipKind: String, Codable, Sendable { case text, image }
  public struct ClipEntry: Codable, Equatable, Identifiable, Sendable {
      public let id: UUID; public let kind: ClipKind; public var copiedAt: Date
      public let sourceApp: String?; public let contentHash: String     // SHA256 hex of primary payload
      public let snippet: String?        // text: first 2,000 chars of plain text; image: nil
      public let charCount: Int?         // text only
      public let pixelWidth: Int?; public let pixelHeight: Int?          // image only
  }
  public struct ClipCandidate: Equatable, Sendable { public let entry: ClipEntry; public let representations: [Representation] }
  public enum ClipClassifier {
      public static let snippetLimit = 2_000
      public static func classify(_ s: PasteboardSnapshot, id: UUID, at: Date) -> ClipCandidate?
  }
  public enum InsertOutcome: Equatable, Sendable { case added(evicted: [UUID]); case movedToTop(existingID: UUID) }
  public struct DaySection: Equatable, Sendable { public let title: String; public let entries: [ClipEntry] }
  public struct ClipHistory: Codable, Equatable, Sendable {
      public static let capacity = 25
      public private(set) var entries: [ClipEntry]                       // newest first
      public init(entries: [ClipEntry] = [])
      public mutating func insert(_ e: ClipEntry) -> InsertOutcome        // dedupe by contentHash: existing moves to top with e.copiedAt
      public mutating func moveToTop(id: UUID, at: Date)
      public mutating func removeAll() -> [UUID]
      public func search(_ query: String) -> [ClipEntry]
      public static func sections(_ entries: [ClipEntry], now: Date, calendar: Calendar, locale: Locale) -> [DaySection]
  }
  ```
- Classification rules (decided here; spec §5.4):
  - Any type `public.file-url` → `nil` (skip whole copy).
  - Image types: `public.png`, `public.tiff`, `public.jpeg`, `public.heic`. Text types: `public.utf8-plain-text`, `public.rtf`, `public.html`.
  - **Image** if an image type is present and plain text is absent, empty, or a single line starting with `http://`, `https://` or `file://`. Primary payload = first image representation; dimensions read via ImageIO `CGImageSourceCopyPropertiesAtIndex` (`kCGImagePropertyPixelWidth/Height`).
  - Otherwise **text** if non-empty plain text is present. Primary payload = plain text UTF-8.
  - Otherwise `nil`. Concealed/transient markers are ignored (everything recorded).
  - `representations` keeps every representation of a recognized type (image + text types above, plus `public.url`), so paste restores formatting.
- `search`: trimmed query, case/diacritic-insensitive substring on `snippet` and `sourceApp`; image entries also match the word `"image"`. Empty query → all entries.
- `sections` titles: `"Today"`, `"Yesterday"`, else `DateFormatter` with `setLocalizedDateFormatFromTemplate("MMMd")` using the given locale/calendar.
